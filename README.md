# Banksalad 가계부 데이터 처리 프로젝트

## 프로젝트 소개
1. 설명: 뱅크샐러드 엑셀 데이터를 기반으로 과소비 패턴을 분석해주는 보조 도구??

2. 주요 기능
  - 뱅크샐러드 엑셀 업로드 및 데이터 처리? 연동?
  - 과소비 패턴 분석

## 프로젝트 개발 원칙
0. **개발 원칙**
  - Think Why (왜 만들어야 하는지?)
  - Make Simple (최대한 단순하게)
  - Do Automize (수동 작업 최소화)

2. **로깅 우선**
  - INFO는 필수 정보, DEBUG는 상세 정보  -> 환경 변수로 디버그 모드 제어(set DEBUG=true)

2. **에러 처리**
  - 파일 I/O 작업은 try-except 필수

3. **가독성**
  - import 순서 : 표준 라이브러리 → 서드파티 → 로컬

4. **독립성**
  - 단일 책임 원칙 준수 / 독립 테스트 및 실행 가능
  - 데이터는 파일로 교환

## 디렉토리
- file/      : 입력 엑셀 파일
- data/      : 변환된 Parquet 파일
- parse/     : 필터링 결과
- logs/      : 로그 파일

## 필요한 추가 모듈
- pandas: 데이터 처리
- openpyxl: 엑셀 파일 읽기
- pyarrow: Parquet 파일 처리
