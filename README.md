## 프로젝트 개발 원칙
0. **개발 원칙**
  - Think Why (왜 만들어야 하는지?)
  - Make Simple (최대한 단순하게)
  - Do Automize (최대한 자동화)

2. **로깅 우선**
  - 모든 작업은 로그로 기록
  - INFO는 필수 정보, DEBUG는 상세 정보
  - 환경 변수로 디버그 모드 제어(set DEBUG=true)

2. **에러 처리**
  - 파일 I/O 작업은 try-except 필수
  - 명확한 에러 메시지와 안전한 종료

3. **가독성**
  - 단계별 주석 구분
  - import 순서/구분 : 표준 라이브러리 → 서드파티 → 로컬

4. **독립성**
  - 각 스크립트는 단일 책임 원칙 준수
  - 각 스크립트는 독립적으로 테스트 및 실행 가능
  - 주요 설정값은 코드 상단에 명시
  - 데이터는 파일로 교환

## 디렉토리
- file/      : 입력 엑셀 파일
- data/      : 변환된 Parquet 파일
- parse/     : 필터링 결과
- logs/      : 로그 파일

## 필요한 추가 모듈
- pandas: 데이터 처리
- openpyxl: 엑셀 파일 읽기
- pyarrow: Parquet 파일 처리
