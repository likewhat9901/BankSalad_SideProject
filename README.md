# Banksalad 가계부 데이터 처리 프로젝트


## 프로젝트 소개
1. 설명: 뱅크샐러드 엑셀 데이터를 기반으로 과소비 패턴을 분석해주는 보조 도구??

2. 주요 기능
  - 뱅크샐러드 엑셀 업로드 및 데이터 처리? 연동?
  - 과소비 패턴 분석


## 프로젝트 개발 원칙
0. **핵심 철학**
  - Think Why : 만들어야 하는 이유
  - Make Simple : 최대한 단순하게 구현
  - Do Automize : 수동 작업 최소화

1. **코드 스타일**
  - import 순서 : 표준 라이브러리 → 서드파티 → 로컬
  - 모듈 사용 : os 모듈 사용 최소화
  - 설정 관리 : 공유 설정은 `config.py`, 개별 설정은 해당 파일에
  - 네이밍 : 상수는 `UPPER_SNAKE_CASE`, 변수/함수는 `lower_snake_case`

2. **유지보수 / 디버그**
  - 로깅레벨 : INFO는 필수 정보, DEBUG는 상세 정보
  - 디버그 모드 : 환경 변수로 디버그 모드 제어(set DEBUG=true)
  - 예외 처리 : 파일 I/O 작업은 try-except 필수
  - 에러 메세지 : 원인과 해결 방법을 명시

3. **모듈 설계**
  - 단일 책임 원칙 : 하나의 파일/함수는 하나의 역할만
  - 독립 실행 가능 : 각 모듈은 개별 테스트 및 실행 가능
  - 데이터 교환 : 모듈 간 데이터는 파일로 교환


## 주요 디렉토리 및 파일
- resData/    : 원본 Excel 파일
- data/       : 변환된 Parquet 파일
- parse/      : 필터링 결과
- logs/       : 로그 파일

- config.py   : 공통 설정값


## 필요한 추가 모듈 (표준 라이브러리 외)
- pandas    : 데이터 처리
- openpyxl  : 엑셀 파일 읽기
- pyarrow   : Parquet 파일 처리
